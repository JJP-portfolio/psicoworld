# Ejercicios D5 — Dificultad y flow

Base: `ENCOUNTER_STEPS` por zona, telegraphs, i-frames, onboarding (casa), flow channel.

1. (Fácil) Ordená las 4 zonas por dificultad según `ENCOUNTER_STEPS`. ¿Coincide con niveles 1-20?
2. (Fácil) ¿Qué es un telegraph? Nombrá 1 que ya existe (pista: no hay aún) y diseñalo para el guardia.
3. (Fácil) i-frames: ¿cuánto duran en `Health`? ¿Qué sentís si duraran 0? ¿Y 5 s?
4. [INTEGRADOR] Auditá la casa como onboarding: ¿qué enseña cada cuarto en orden? (mover → puerta → dueño → símbolo). Integrás mapa + curva.
5. (Medio) Primera batalla (Beat 5): stats de los 2 guardias para que sea ganable pero tensa (números).
6. (Medio) Diseñá 3 oleadas tutorial (1 lento → 2 → 1 rápido + 1 tanque) con hp/daño.
7. (Medio) Flow: ¿dónde puede aburrirse (fácil) o frustrarse (difícil) el jugador hoy? 1 caso cada uno.
8. [INTEGRADOR] Tabla de dificultad por acto (1-4): enemigos, daño, hp, frecuencia, poder requerido. Integrás mundo + números + progresión.
9. (Difícil) Modos Active vs Wait (doc ATB): ¿cuál para PsicoWorld y por qué? (pilares + público.)
10. (Difícil) Diseñá el fail state con dignidad: ¿qué pasa al morir? (no solo "game over".)
