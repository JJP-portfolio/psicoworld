# Ejercicios D2 — Core loop

Base: loop 30 s (momento a momento), 5 min (sesión), multi-sesión. Todo loop: acción → feedback → progreso.

1. (Fácil) Escribí el loop de 30 s actual (caminar → ver → chocar → ...).
2. (Fácil) Escribí el loop de 5 min actual (spawn → casa → diálogo → salir).
3. (Fácil) Marcá en código dónde vive cada paso del loop (archivos:líneas).
4. [INTEGRADOR] Dibujá el loop completo con sus recompensas (qué gana el jugador en cada vuelta). Integrás diseño + código real.
5. (Medio) Detectá el "hueco": ¿qué vuelta no devuelve nada hoy? (Pista: pelear.)
6. (Medio) Diseñá el loop de combate futuro (entrar arena → esquivar → pegar → loot) en 5 pasos.
7. (Medio) Loop de la hija: ¿qué hace ella mientras tanto? (mundo vivo en 3 líneas de guion.)
8. [INTEGRADOR] Conectá los 3 loops (30 s, 5 min, combate) en un diagrama + qué archivo toca cada flecha. Integrás sistemas.
9. (Difícil) Regla de oro: ningún loop sin recompensa visible en < 2 min. Auditá el juego actual.
10. (Difícil) Escribí el loop objetivo post-Beat-5 (con primera batalla incluida).
