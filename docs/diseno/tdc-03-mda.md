# TDC-03 Matriz MDA — Resumen fiel + ejercicios (parcial)

Fuente: `~/unahur/TallerDeDiseñoConceptual/markdown/03-MatrizMDA.md`. Autores: Hunicke, Zubek, LeBlanc.

## Resumen

- **Flujo:** Diseñador: Mecánicas → Dinámicas → Estéticas. Jugador: al revés (siente ← juega ← reglas).
- **Mecánicas:** reglas, acciones, algoritmos, estructuras (Minecraft: poner/romper bloques).
- **Dinámicas:** comportamiento en tiempo real que EMERGE (construir, explorar). Fomentadas (planeadas) vs inesperadas (no planeadas).
- **Estéticas (8 diversiones):** sensación, compañerismo, desafío, fantasía, narrativa, descubrimiento, expresión, sumisión.
- **Cómo usar:** 1º elegir estéticas → 2º dinámicas que las logran → 3º mecánicas que las fomentan.
- Ejemplo apunte (plataformas): Desafío ← atravesar obstáculos a tiempo ← física/tiempo/saltar.
